# ScamShield Website

This repository hosts the public static website for ScamShield, including its product homepage, privacy-policy URL, and support URL. The site uses only HTML and CSS and requires no build process, package installation, environment variables, or server.

## Publish with GitHub Pages

1. Push the completed site to GitHub.
2. Open the repository on GitHub.
3. Open **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose `Deploy from a branch`.
6. For **Branch**, select `main`.
7. For **Folder**, select `/ (root)`.
8. Select **Save**.
9. Wait for the GitHub Pages deployment to finish.
10. Open the generated public HTTPS URL.

The final URLs will normally be:

```text
https://<username>.github.io/<repository>/
https://<username>.github.io/<repository>/privacy.html
https://<username>.github.io/<repository>/support.html
```

Use the URLs in browser-extension store submissions as follows:

- **Developer website** → homepage
- **Privacy policy URL** → `privacy.html`
- **Support URL** → `support.html`

## Required content before publication

- Replace `[APPROVED PRIVACY POLICY CONTENT REQUIRED BEFORE PUBLICATION]` by faithfully converting the approved ScamShield `PRIVACY.md` into semantic HTML.
- Replace `[SUPPORT_EMAIL_REQUIRED]` with the real support email address and make it a `mailto:` link.
- Add only approved, redacted screenshots to `assets/screenshots/`.
- Add the approved ScamShield icon to `assets/logo/` if available, then use it as the site icon and favicon.

Do not invent publisher details, contact information, or policy terms.
